# example

A tiny Node.js practice project from 2021. It prints a few lines of text to the console and was used to try out a basic Git and GitHub workflow, including a pull request.

## What it does

- `index.js` prints "Hello" and "World".
- `ios.js` prints "iPhone 11".

There is no user interface, no server and no network access.

## Tech stack

- JavaScript
- Node.js (no dependencies, nothing to install)

## How to run

You need Node.js installed. Then, from the repository root:

```bash
git clone https://github.com/maxawad/example.git
cd example
npm start      # runs index.js
npm run ios    # runs ios.js
```

You can also run the files directly with `node index.js` and `node ios.js`.

## Try it online

This is a command line script, so it has no live demo. The code is short enough to read and run in any online Node.js playground.

## Status

Working, but only a small demo. It does not need any API keys.
